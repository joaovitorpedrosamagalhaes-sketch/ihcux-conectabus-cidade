ALUNOS : Caua Furst, João Vitor Pedrosa Magalhães, Luiz Guilherme Thomaz, Silas Caleb.

Contexto de Uso :
O aplicativo foi pensado para usuários em deslocamento urbano que precisam tomar decisões rápidas durante a rotina. Um exemplo de uso é uma pessoa correndo para não perder o metrô ou tentando encontrar a rota mais rápida em horário de pico. O app também auxilia estudantes, trabalhadores e turistas em ambientes externos e movimentados.

Decisões de UX :
As principais decisões de UX foram feitas para reduzir a carga cognitiva e facilitar a leitura rápida das informações.

O tempo de chegada e duração da rota foram destacados visualmente por serem as informações mais importantes para a tomada de decisão.
A lotação dos veículos foi apresentada de forma visual e simples (vazio, moderado e lotado).
O QR Code da carteira digital foi centralizado e ampliado para facilitar o pagamento rápido.
Os botões possuem tamanho maior para facilitar o uso em movimento.
A navegação foi simplificada para evitar excesso de informações na tela.

Acessibilidade : 
O protótipo foi desenvolvido pensando em acessibilidade e praticidade.

Os elementos clicáveis possuem tamanho ampliado, facilitando o toque para pessoas com mobilidade reduzida.
As informações mais importantes possuem destaque visual para leitura rápida.
Ícones simples ajudam usuários com dificuldade de leitura.
A tela de detalhes do veículo informa recursos de acessibilidade, como rampas e ar-condicionado.
O botão de segurança permanece visível durante toda a navegação para acesso rápido em emergências.
O fluxo de uso foi reduzido para que o usuário consiga concluir tarefas rapidamente mesmo em situações de pressa.
